# AC Runtime

> Core runtime library for the AC Runtime component framework.

## Overview

`ac-runtime` provides the decorators, interfaces, helpers, and router that AC Runtime component authors use in their source code. These are **compile-time markers** — the actual Web Component code is generated by [`ac-runtime-compiler`](../ac-runtime-compiler/).

## Installation

```bash
npm install @autocode-ts/ac-runtime
```

## Exports

### Decorators

| Decorator | Target | Description |
|-----------|--------|-------------|
| `@AcElement(metadata)` | Class | Marks a class as an AC component with a selector, template, and optional styles. |
| `@AcInput(alias?)` | Property | Marks a property as an external input (maps to an HTML attribute). |
| `@AcOutput(alias?)` | Property | Marks a property as an event emitter (compiled to `CustomEvent` dispatching). |
| `@AcViewChild(selector)` | Property | Provides a live DOM reference to a template element marked with `#ref`. |

### Lifecycle Interfaces

| Interface | Method | When Called |
|-----------|--------|------------|
| `IAcOnInit` | `acOnInit()` | After first render (in `connectedCallback`). |
| `IAcOnDestroy` | `acOnDestroy()` | Before removal (in `disconnectedCallback`). |
| `IAcOnConnected` | `acOnConnected()` | Element inserted into DOM. |
| `IAcOnDisconnected` | `acOnDisconnected()` | Element removed from DOM. |
| `IAcOnChange` | `acOnChange(change)` | Any reactive property changed. |
| `IAcOnPropertyChange` | `acOnPropertyChange(change)` | A specific property changed. |

### Helpers

| Export | Description |
|--------|-------------|
| `AcEventEmitter<T>` | Typed event emitter for `@AcOutput()` properties. |
| `acRouter` | Singleton router instance. |
| `AcRouterElement` | `<ac-router>` custom element for route rendering. |
| `IAcRoute` | Route definition interface. |

## Template Syntax

```html
<!-- Text interpolation -->
<span>Hello {{name}}</span>

<!-- Property binding -->
<input [value]="name" />

<!-- Event binding -->
<button (click)="handleClick()">Click</button>

<!-- Two-way binding -->
<input ac:model="name" />

<!-- Class toggle -->
<div [class.active]="isActive">...</div>
<div ac:class:active="isActive">...</div>

<!-- Style binding -->
<div [style.color]="textColor">...</div>
<div ac:style:color="textColor">...</div>

<!-- Attribute binding -->
<div ac:bind:title="tooltip">...</div>

<!-- Conditional rendering -->
<div ac:if="isVisible">Shown when true</div>

<!-- List rendering -->
<div ac:for="item of items">{{item}}</div>

<!-- Template reference -->
<input #myInput type="text" />

<!-- Virtual container (renders children only, no wrapper tag) -->
<ac-container>
  <span>A</span>
  <span>B</span>
</ac-container>
```

## Example

```typescript
import { AcElement, AcInput, AcOutput, AcViewChild, IAcOnInit } from 'ac-runtime';
import { AcEventEmitter } from 'ac-runtime';

@AcElement({
  selector: 'user-card',
  template: `
    <div class="card">
      <h2>{{name}}</h2>
      <p ac:if="bio">{{bio}}</p>
      <button (click)="handleClick()">Select</button>
      <input #searchInput type="text" ac:model="query" />
    </div>
  `,
  styles: ':host { display: block; padding: 16px; }'
})
export class UserCard implements IAcOnInit {
  @AcInput() name = 'Anonymous';
  @AcInput() bio = '';
  @AcOutput() selected = new AcEventEmitter<string>();
  @AcViewChild('searchInput') searchInput!: HTMLInputElement;

  query = '';

  acOnInit() {
    this.searchInput.focus();
  }

  handleClick() {
    this.selected.emit(this.name);
  }
}
```
